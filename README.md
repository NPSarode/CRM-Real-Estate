# 🏘️ CRM-Real-Estate

**CRM-Real-Estate** is a mobile application designed to streamline property lead management for real estate businesses. It offers a modern, intuitive interface for managing leads, updating lead status, tracking interactions, and controlling user access through roles. Built with **React Native**, this app is backed by a powerful API that ensures real-time data handling and secure operations.

---

## 📱 Features

- 🔍 View all, active, and pending leads
- ✅ Update lead statuses with ease
- 📇 Manage contact details and lead history
- 🔐 Role-based authentication and access control
- 📊 Dashboard with quick insights
- ⚙️ User profile and settings screen
- 🔄 Seamless integration with backend services

---

## 🧰 Tech Stack

### Mobile Frontend
- **React Native**
- **React Navigation** – Navigation between screens
- **Axios** – For API calls
- **Tailwind CSS (via NativeWind)** – Optional styling utility

### Backend (Optional Stack)
- **Node.js**, **Express.js**
- **Postgres** or **PostgreSQL**
- **JWT** – For secure authentication

---

## 📦 Installation

### Prerequisites

- Node.js
- Expo CLI or React Native CLI
- Android Studio / Xcode (for emulators)
- Backend server running (if connected)
